# Política de privacidad · Pasta Clara

Última actualización: 24 de noviembre de 2026.

«Pasta Clara» es una herramienta interna que usa la API de datos de YouTube (YouTube API Services) para publicar de forma programada vídeos en el canal de YouTube Pasta Clara, con autorización de su titular.

**Qué datos usa.** Solo accede a la cuenta de YouTube del propio canal Pasta Clara para subir vídeos y leer información básica del canal (nombre y lista de vídeos subidos). No recoge, almacena, vende ni comparte datos personales de terceros.

**Almacenamiento.** Las credenciales de acceso se guardan cifradas como secretos del sistema de automatización y solo se usan para publicar en el canal.

**Terceros.** Se aplican los [Términos de servicio de YouTube](https://www.youtube.com/t/terms) y la [Política de privacidad de Google](https://policies.google.com/privacy).

**Revocar el acceso.** En cualquier momento desde [los permisos de la cuenta de Google](https://myaccount.google.com/permissions).
